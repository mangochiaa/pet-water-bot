# Pet Water Tracker

Telegram-бот на Python, который помогает владельцам питомцев следить за графиком питья воды.

## Возможности

- `/start` — приветствие и меню с кнопками
- `/add_pet` — пошаговое добавление питомца (имя, вид, вес в кг)
- `/pets` — список всех питомцев
- `/water` — отметить, что питомец попил воды (выбор через Inline-кнопки)
- `/stats` — статистика за сегодня
- `/help` — справка
- `/cancel` — отменить добавление питомца

Данные хранятся локально в файлах `pets.json` и `water_log.json` (создаются автоматически при первом сохранении).

## Требования

- Python 3.9 или новее
- Токен бота от [@BotFather](https://t.me/BotFather)

## Установка и запуск

1. Клонируйте репозиторий или скопируйте файлы проекта.

2. Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

На Windows вместо `source .venv/bin/activate` используйте `.venv\Scripts\activate`.

3. Создайте файл `.env` по образцу:

```bash
cp .env.example .env
```

4. Откройте `.env` и вставьте токен:

```
BOT_TOKEN=123456:ABC-ваш-токен-от-BotFather
```

5. Запустите бота:

```bash
python bot.py
```

6. В Telegram найдите своего бота и отправьте `/start`.

## Структура проекта

```
pet-water-bot/
├── bot.py            # основной код бота
├── requirements.txt  # зависимости
├── .env.example      # пример переменных окружения
├── .env              # ваш токен (не публикуйте этот файл)
├── pets.json         # питомцы (создаётся ботом)
└── water_log.json    # журнал поения (создаётся ботом)
```

## Как получить токен

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и следуйте инструкциям.
3. Скопируйте выданный токен в файл `.env`.
